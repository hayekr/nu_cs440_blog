## Key Idea
The authors introduce a Network Decision Diagram (NDD) that aims to improve on memory efficiency, computational efficiency, and network verification support. The authors demonstrate the memory and computational speedup using multiple virtualized network datasets. Additionally, the authors release their NDD implementation as a library that can be used directly for network verification.


## Critique
The paper compares NDD vs. BDD and claims a 100x improvement when using NDD. When the authors use the modified Purdue dataset with different ACL rules, they demonstrate that the gains depend on field locality. When rules match all five fields, NDD's atom count and running time increase linearly, while BDD's decrease. This limits their claim that NDD is a drop-in replacement for BDD. Additionally, the authors rely on synthesized workloads, i.e., modified ACL rules that match all fields, which may not reflect real systems.
